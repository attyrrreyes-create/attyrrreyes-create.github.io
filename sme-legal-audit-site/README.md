# SME Legal Exposure Audit — Static Site

This is a lightweight static site for performing a quick SME legal exposure self-audit.

How to use

- Open [sme-legal-audit-site/index.html](sme-legal-audit-site/index.html) in a browser.
- Complete the questionnaire and click "Calculate Risk".
- Print or save the results as PDF using the browser print dialog.

Notes

- This tool is informational only and does not constitute legal advice.
- The questionnaire and scoring are a simple approximation based on common SME risk domains; refine weights and questions to match your practice.
